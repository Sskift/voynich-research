# 第十五轮：词序和局部相似词能告诉我们什么

**仍未破解。实验019已完成对照、手稿固定评分和两套独立审计。**
本轮暂不拟合字母值，而是检验下一种解码模型需要解释哪些顺序结构。
先把普通文本、独立抽词文本、复制并修改前词的生成文本分别加密，检查
三个固定统计量能否识别已知差异，再按同样规则测量手稿。

## 数据和预先固定的比较

训练数据实际覆盖78页、980行、6,586个可辨词槽。主比较集为16页草本
正文，185行、1,242个可辨词槽；章节迁移集为16页制药正文，223行、
2,449个可辨词槽，另31个未知整词保留为断点。全部都是以前研究过的
开发资料，f49v、f58r、f58v未使用。

此前沿用的“79H”是候选页分组名称，其中f49v没有进入冻结选择的任何行，
实际一直只使用78页。已单独保存[范围澄清](experiment-019-scope-clarification.md)，
核对了四代输入中的980个训练行位置及原始GC文本完全一致；没有更换数据。

对照仍来自Caesar→Cicero、Brant→Tepl、Dante→Boccaccio三个跨作品组合。
每组保留原词序，或在该分段的词池中独立抽词，或在有历史的可辨词槽上
以二分之一概率复制前面至多八词中的一个，再等概率保留、替换、插入或
删除一个字母。
复制发生在加密之前；这是本轮指定的一个生成器，不代表所有复制模型。

四种编码分别是一对一、均匀127码同音替换、带行位置偏好的127码，以及
把真实空格加密后随机重新分组的127码。前三种保持词界；最后一种的
可见词界是假的，其可见词数也不同。对照匹配页、行及原始词槽数量，
没有挑选或截短源词去匹配手稿的字形长度。源记录边界是额外的上下文断点。

三个统计量及其用途如下。

| 指标 | 固定定义 |
|---|---|
| 整词预测增益 | 前词预测后词，相对于只用后词频率的平均自然对数增益；回退质量100 |
| 词边缘预测增益 | 前词末两个字形预测后词首两个字形；两词长度均至少2；回退质量10 |
| 局部相似词比例 | 同一连续片段内、距离1至8的前后词对中，编辑距离恰好为1的比例 |

两个预测模型只在训练数据拟合。未知整词中断上下文，训练未见的可辨
字形仍保留；词汇未登录项进入同一个UNK桶，未见上下文精确退回基线。
预测词对限于同一物理行；局部相似词可以跨相邻行，但不能跨段落、缺行、
页界或未知词。完全相同的词对另报，不计入“恰好一次编辑”的主检验。

每个数据集的每个比较分段均做999次同一套置换：只在同页、同段首行标记、
同首中尾位置、完全相同字形长度和相同片段首尾状态内交换完整可辨词。
训练模型不重训。每个分段的三个指标使用0.05/3门槛；预测还必须优于
相应的边际频率基线，不能仅因“比打乱后损失小”就通过。页面重采样区间使用
1,999次计数加权bootstrap，训练模型和置换均值保持固定。

151项输入先于新计数冻结，随后冻结48个准备文件。36组编码对照以及
9组未编码不变性检查全部完成后，校准冻结清单另记录51项；实际评分必须
核验这条链。九组一对一编码的全部统计、置换和区间与未编码版本一致。
不同编码共享同一作品，不能当作额外的独立语言样本。

## 已知对照揭示的方法边界

预先要求：一个预测指标必须在三组普通文本上全部通过，才称作在该编码
下展示了足够的校准敏感性。结果没有任何编码满足这一要求。

| 编码 | 主比较：普通文本整词指标通过数 | 主比较：普通文本词边缘通过数 | 主比较：复制判别模式通过 | 章节迁移：复制判别模式通过 |
|---|---:|---:|---|---|
| 一对一 | 1/3 | 0/3 | 是 | 是 |
| 均匀127码 | 0/3 | 0/3 | 否 | 是 |
| 行位置127码 | 1/3 | 0/3 | 否 | 否 |
| 隐藏真实空格127码 | 0/3 | 0/3 | 否 | 否 |

章节迁移集的两个普通文本预测指标在所有编码下均为0/3。主比较的一对一
编码中，拉丁文整词增益为+0.043600，德文为−0.061750，意大利文为
−0.084785；三者相对于置换的p值都是0.001，但后两者仍劣于词频基线，
所以按原定规则不通过。不能把一个很小的置换p值写成有效的语言预测。

“复制判别模式”要求三组复制文本都通过局部相似词检验，而对应普通文本
和独立抽词文本均不通过，且九个检验都有可移动信息。它只描述这批预定
对照的门槛模式；未显著不是零效应，也不等于正式证明机制之间有差异。

在一对一主比较中，复制文本的局部相似词实际比例／置换均值分别为：
拉丁文7.6715%／3.8349%，德文8.0469%／4.0330%，意大利文9.5856%／
6.1097%，三者p均为0.001。均匀127码下，主比较只能检出德文复制文本；
行位置编码下，拉丁文独立抽词对照也通过了门槛（p=0.004），因此严格
判别条件失败。章节迁移中更好的均匀编码结果不能替换预定的主比较。

隐藏词界后，“独立抽词”只指明文词独立，重新分组的可见词未必独立。
这些失败结果都保留。它们说明不能用弱信号排除语言或复制，亦不能因为
手稿某项通过就直接选定生成机制。

## 手稿固定指标

在全部校准结果冻结、输入审计通过后，只运行一次手稿评分。两个预测
指标以每个合格词对的自然对数增益计；局部相似词以比例计。

| 比较分段与指标 | 实际值 | 置换均值 | 单侧p | 预定标准通过 |
|---|---:|---:|---:|---|
| 草本主比较：整词增益 | −0.046463 | −0.096379 | 0.001 | 否 |
| 草本主比较：词边缘增益 | −0.263778 | −0.423800 | 0.001 | 否 |
| 草本主比较：一次编辑词对 | 363/8,928 = 4.0659% | 4.0385% | 0.440 | 否 |
| 制药章节迁移：整词增益 | −0.043048 | −0.084060 | 0.001 | 否 |
| 制药章节迁移：词边缘增益 | −0.326318 | −0.548790 | 0.001 | 否 |
| 制药章节迁移：一次编辑词对 | 689/16,967 = 4.0608% | 3.7579% | 0.008 | 是 |

两个预测指标都对条件置换敏感，但固定训练模型在原始顺序上仍不如频率
基线。这支持“存在本置换会破坏的顺序结构”的有限描述，不能写成成功的
语言模型。草本整词增益的页面bootstrap95%区间为[−0.065170,−0.024457]，
词边缘为[−0.337030,−0.184802]；制药组分别为
[−0.063096,−0.022429]和[−0.379440,−0.276941]，全部低于零。

草本局部相似词超额只有0.0274个百分点，页面区间为[−0.2082,0.2322]
个百分点；制药组为0.3029个百分点，区间[0.0571,0.5580]个百分点。
两个分段的原始相似词比例很接近，置换基线却不同。因此不能只看原始
相似词很多，就认定局部复制；也不能把“一个显著、另一个不显著”说成
已经检验了章节间效应差异。制药组是预先命名的迁移检查，不能取代主比较。

草本可移动词槽为1,072/1,242（86.31%），制药组为2,216/2,449（90.49%），
全部六项检验都有置换变异，页面bootstrap没有零分母抽样。草本整词预测
共1,057对，其中训练实际见过126对；词边缘预测948对，其中见过736对。
这些覆盖信息与分数一同保留，未知项没有被删除来制造连续上下文。
完全相同词对的局部比例分别为0.8513%和0.8074%，仅作描述，没有追加检验。

本轮给下一步的约束是：应同时解释对置换敏感、但当前跨页预测仍不及
频率基线的词序结构，以及主比较中没有明确局部一次编辑超额的结果。
不能据此排除自然语言、所有复制过程或任何整种语言；尤其已有对照证明
编码和错误词界会掩盖信号。这里没有可验证的连续译读，也没有从统计量
推导字形读音或词义。

## 独立审计与复现

输入审计已通过：690次SHA核对，覆盖151项输入、48项准备文件及旧来源
冻结链；独立重建1,388行、10,308个词槽、9组明文共92,772个生成词槽、
36组编码的全部观测、随机数消费、未知槽、断点、隐藏空格会计和92组测试
种子。审计器没有调用生产生成函数。

独立统计审计也通过：46组数据、92个测试分段，重放275,724个置换指标值和
551,724个页面bootstrap指标抽样，核对9组双射不变性及24组校准标签。
训练计数用独立Counter重建，核对其汇总和全部实际／置换统计；生产结果
没有保存的内存计数表不被声称逐项对照。编辑距离使用Trie上的动态规划，
而非生产代码的删除签名算法。最大数值差异为9.09×10⁻¹³，307次冻结哈希
校验均通过（包含重复核验）。全部进程正常结束，没有重跑选择更好的结果。

先在给出真密钥的条件下检查固定省写后的连续原文能否恢复，再考虑未知
密钥搜索。它尚未冻结或运行，019也没有为该机制提供正面识别证据。

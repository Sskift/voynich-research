# Character-source clarification during v2 known-cipher calibration

No mapping/model/output value changes. The archived TITUS u and a tables directly
confirm E72B/E72D and E42C. Its older o table labels o-with-e-above E638, NOT E644.
Thus the frozen v2 amendment's shorthand that all four codepoint definitions agree
with those particular archived TITUS pages was too broad. E644 is instead confirmed
by MUFI v4 alphabetical p76 / code-chart p154 (official search-index content) and
the separately archived OCR-D character coding table. The latter explicitly gives
E644 = o + combining e (0364). This clarification supersedes that source-attribution
sentence without altering the frozen projection or claiming the old table uses E644.

- https://mufi.info/mufi/pdfs/MUFI%20v4.0%20chart.pdf

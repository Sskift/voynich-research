# 第一轮：从版面约束入手，而不是猜语言

日期：2026-10-02。**没有得到经过验证的译文，破解目标仍未达成。**
本轮建立了可复现数据基础，检验了一个具体的字形还原假说，并留下
可继续验证的候选。这不是宣布新发现；位置效应已有长期研究。

耶鲁的[馆藏说明](https://beinecke.library.yale.edu/beinecke/collections/beinecke-cipher-voynich-manuscript)
仍把手稿文字视为未解读。对近期声称成功的材料，本轮没有找到足以
采纳为解码基础的独立验证；也没有穷尽审查所有此类主张。

## 数据可信度

使用 Zandbergen 提供的 [ZL3b 与 IT2a](https://www.voynich.nu/transcr.html)。
前者源于 Zandbergen–Landini 的工作，后者是 Takahashi 转写的历史版本。
它们是同一本手稿的不同读法，不能当作两本独立手稿样本；共享的版面
元数据也会带来相关性。另下载的 RF1b 是合成参考版，没有用作第三次独立验证。

| 项目 | ZL3b | IT2a |
|---|---:|---:|
| 转写位置数（loci） | 5,385 | 5,215 |
| 文件中的页标识数 | 227 | 225 |
| 段落标记对数 | 740 | 772 |
| 拆开不确定空格后的符号串数 | 39,026 | 37,919 |
| 保守接受的符号串数 | 37,889 | 37,759 |
| 排除的不确定符号串数 | 1,137 | 160 |

合并 ZL 的不确定空格得到 36,278 个符号串，与提供者公布的总数一致。
位置数、段落数和 IT 的词数也与其表格吻合。原文件有 SHA-256 记录。
段落标记配对、词位保留、注释与图形间隔的处理均已检查。
具体见 [audit.json](../results/audit.json)。

主要分析只取正常左对齐的 P0 行，排除明确有同排续段的截断行。
行末检验要求整行读法确定、至少三个词。因而结果不是不加区分的
“全书所有文字统计”，也不覆盖环形文字、图旁标签和罕见字形。

## 1. 行尾 m：位置关系很强，但对应的普通词形不唯一

这里的 `m` 是 EVA 字形代码，不是拉丁字母的读音。

| 数据处理 | 合格行数 | 行末词以 m 结尾 | 同行其他位置的平均比例 |
|---|---:|---:|---:|
| ZL，不确定空格拆分 | 3,070 | 15.70% | 0.89% |
| IT | 3,746 | 16.52% | 1.00% |
| ZL，不确定空格合并 | 3,060 | 15.72% | 0.94% |

“同行其他位置”先在每一行求比例，再对行平均，与每行仅有一个行末词
相配对；它不是把所有非末词直接混在一起算的比例。
ZL 拆分版的平均差为 **14.81 个百分点**，按页聚类自助区间为
12.94–16.76 个百分点。行内随机选择末位的检验，1,999 次随机化
没有一次达到观测差值，校正后的单侧 p=0.0005；这不是 p=0。

为排除 ZL 比 IT 丢弃更多模糊行的影响，也只比较两版共同的 3,051 行：
ZL 为 15.70% 对 0.886%，IT 为 16.13% 对 0.934%。方向保持一致。
A、B 两类文本和各书手分组也都同向；小书手组的样本量很小，不能
声称其效应量精确。

**可以推断：任何解码模型都必须解释行位置与该字形的强关联。**
这与缩写、异体字、行尾处理或某种生成规则相容。它本身不能证明
是哪一种机制，更不能确定语言。

## 2. 段首的差异并不局限于第一个字

在主要 ZL 分析中，段落第一行有 22.46% 的词含 `p` 或 `f`，其余
段内行是 1.27%；IT 为 22.46% 对 1.32%。这是字形编码包含关系，
包括组合字形中的 p/f；并未把它们全部认定为独立字母。

在整行无模糊读法的样本中，**去掉每行第一个词**后，这两个比例仍是
18.51% 对 1.15%（ZL）、18.62% 对 1.26%（IT）。仅仅改变段首
第一个字的大小写，不足以解释这个现象。但这也不排除更广泛的书写惯例。

这一结果属于对既有位置规律的复核。可对照 Stafford 的
[Seven Habits of Highly Eccentric Paragraphs](https://ceur-ws.org/Vol-3313/paper13.pdf)，
以及 [Currier 的原始观察](https://www.voynich.nu/extra/curr_main.html)。
本轮没有逐表复现其不同筛选条件下的全部结果。

## 3. 实际尝试：把 m 展开成其他词尾

先按叶号固定训练／留出划分，同一叶正反面始终同组。用训练叶的
非行末词建立词表，再尝试还原留出叶的行末 m。ZL 拆分版共有
274 个这样的测试词。

| 操作 | 还原后能在训练词表找到的比例 |
|---|---:|
| 保留 m | 45.62% |
| 删除 m | 39.05% |
| m → r | 71.17% |
| m → l | 70.07% |
| m → iin | 70.07% |
| m → in | 59.12% |
| m → n | 17.52% |
| m → y | 8.03% |

例如 `dam` 可以变成训练语料中都常见的 `dar`、`dal`、`daiin`。
“变成一个已存在的词”无法在这些解释中作出选择。对 `om`，对应的
`or`、`ol` 又比 `oiin` 常见。保留所有候选，不能逐词挑一个最顺眼的
输出再称为统一规则。

加入前一个词的简单二元模型后，整体评分略偏向 `iin`，但 Currier A
多偏向 `r`，B 多偏向 `iin`。ZL 主条件的整体二元平均分为 -11.470
bits（iin）与 -11.617（r）；IT 几乎相同，为 -11.473 与 -11.483。
这些是特定模型的评分，不是字形等价的概率。

模型相对单词频率基线并没有获得平均上下文增益；常见正常词尾的
校准组也有类似问题。因此**不能用这个弱上下文模型否定某个候选**，
也不能把略高的整体分数视为 m=iin 的证明。它可能受数据稀疏、
章节词频及训练只用非行末位置的分布差异影响。
这一后续实验发生在看过第一轮留出结果之后，明确属于探索性分析。

## 4. 相邻重复：对照组的选择会改变结论

对每行去掉首尾词，再保持这行的词汇及词频不变、随机打乱中间词。

| 数据 | 实际相邻同词次数 | 随机排列的精确期望 | “比随机更多”的单侧 p |
|---|---:|---:|---:|
| ZL 拆分 | 196 | 217.45 | 0.963 |
| IT | 236 | 249.56 | 0.879 |
| ZL 合并 | 172 | 177.39 | 0.687 |

三个按页聚类的重复率差区间都含零。这个检验没有发现稳定的**行内、
紧邻、完全相同词**重复过量。它不检验近似拼写、跨行复制、长距离
重复或局部词汇如何形成。把行词表固定也可能已条件化掉某些复制
机制的信号，所以不能据此证明有语言或推翻所有复制生成假说。

补充：保留首尾词时，ZL 合并空格版的随机化 p=0.0275，另两版不显著，
其按页聚类区间仍含零。因此不能把“所有排列检验都没有信号”当作结论；
边界处理和空格解释会影响结果。

## 下一步真正需要解决的事

目前还没有任何经过验证的词义。可靠的下一步是用图片对象和可识别
历史材料建立外部约束，而不是扩大任意换字的自由度：

1. 从药草部的 Lf/Lc 标签入手，保留相邻图像对象、页码及两版转写
   分歧，建立可核对的标签表。先验证同一标签是否稳定指向同类对象；
   不先指定植物种名。
2. 在同书手、同图像章节内，比较 m 候选与上下文、词根及图旁标签的
   关系；使用新的按叶分组验证，避免沿用已经反复查看的留出集作最终证明。
3. 若要检验“拉丁文简单替换”等具体主张，先用确实可解的同时代
   对照文本检验求解器，再报告固定字表在未参与拟合页上的输出。
   本轮的位置统计尚未排除一个完整密码家族。

只有固定规则能持续给出语言上、图像上、历史上相互支持的译文，并
通过独立验证，才可以称为破解。当前证据距离这个要求仍有实质差距。

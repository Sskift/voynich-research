# Position controls for label spelling profiles

2026-10-02. Exploratory follow-up after experiment 005 found o-initial enrichment,
qo-initial depletion, and terminal-m enrichment in length/page-matched labels.
The 670-rule screen failed to find a useful general rule (maximum-search p=.991),
and frozen external evaluation has finished. Do not refit that rule on its target
pages. An online source check also found Landini's 2001 o/q label count and later
research discussing label versus line/paragraph boundaries. These are known
phenomena, not discoveries of this project.

For each of ZL split, IT split and ZL join, use the same 131 agreed plant labels.
Body controls: eligible complete ordinary P0 lines, excluding continuation and
unknown tokens without closing gaps. Compare all positions, first word of a
paragraph, first word of a non-first paragraph line, internal words, last word
of any eligible line. Preserve same page and exact EVA string length. Report
both token weighting and unique-type weighting. A label with no matching pool
is excluded for that comparison; report every support count and exclusion.
For fair effects within each position contrast, compare with ALL-position
controls on that same support subset. No across-column comparison of unmatched
sample means. A single label is simultaneously at both ends, so no one of these
controls is a complete model of isolated-label layout.

Only three planned follow-up features: initial o, initial qo, terminal m. Report
rates and paired differences descriptively, with page-specific counts. Small
number of pharmaceutical leaves and nonrandom semantic roles limit inference.
Do not infer a cipher key from marginal prefix frequencies.

Also extract fixed-rule diagnostics from the frozen training set (o->qo,
o->empty; final m->r/l/iin and y->dy), without changing the selected model or
external outcome. These were inside the candidate family. The q diagnostic is
motivated by the newly inspected marginal profiles, so label it exploratory.
